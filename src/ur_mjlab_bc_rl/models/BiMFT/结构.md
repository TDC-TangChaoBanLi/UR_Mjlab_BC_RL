# BiMFT-Policy 完整模型结构与符号化前向传播

**全称：Bimanual Multimodal Fusion Transformer Policy**  
**中文名称：双臂多模态融合 Transformer 策略网络**

---

## 1. 模型目标

BiMFT-Policy 面向双机械臂悬空轴孔装配。两台机械臂分别抓持带轴零件与带孔零件，模型同时利用：

- 左、右手眼 RGB-D 图像序列；
- 全局 RGB-D 图像序列；
- 左、右机械臂关节与夹爪状态序列；
- 左、右末端六维力/力矩序列；

输出左右机械臂未来一段时间内的连续动作块。

整体映射写为：

$$
\left(
\mathbf X^{L},
\mathbf X^{R},
\mathbf X^{G},
\mathbf S^{L},
\mathbf S^{R},
\mathbf W^{L},
\mathbf W^{R}
\right)
\longmapsto
\left(
\widehat{\mathbf A}^{L},
\widehat{\mathbf A}^{R}
\right).
$$

输入、输出维度分别为：

$$
\begin{aligned}
\mathbf X^{c}
&\in
\mathbb R^{B\times T_v\times C_I\times H_I\times W_I},
\qquad c\in\{L,R,G\},\\
\mathbf S^{a}
&\in
\mathbb R^{B\times T_v\times R_q\times D_s},
\qquad a\in\{L,R\},\\
\mathbf W^{a}
&\in
\mathbb R^{B\times T_v\times R_f\times D_w},
\qquad a\in\{L,R\},\\
\widehat{\mathbf A}^{a}
&\in
\mathbb R^{B\times K\times D_a},
\qquad a\in\{L,R\}.
\end{aligned}
$$

# 2. 符号说明

## 2.1 索引与集合

| 符号 | 含义 |
|---|---|
| $a$ | 机械臂索引，$a\in\{L,R\}$ |
| $L$ | 左机械臂或左手眼相机 |
| $R$ | 右机械臂或右手眼相机 |
| $G$ | 全局相机 |
| $c$ | 相机索引，$c\in\{L,R,G\}$ |
| $b$ | batch 中的样本索引 |
| $k$ | 视觉时间槽索引，$k\in\{1,\ldots,T_v\}$ |
| $r$ | 单个视觉周期内的高频采样索引，对于关节 $r\in\{1,\ldots,R_q\}$，对于力觉 $r\in\{1,\ldots,R_f\}$ |
| $p$ | 视觉空间 token 索引，$p\in\{1,\ldots,N_v\}$ |
| $j$ | 动作块中的未来动作索引，$j\in\{1,\ldots,K\}$ |
| $\ell$ | Transformer 层索引 |

## 2.2 数据维度

| 符号 | 含义 |
|---|---|
| $B$ | Batch size |
| $T_v$ | 输入视觉历史帧数 |
| $R_q$ | 每个视觉周期对应的关节/夹爪状态高频采样数 |
| $R_f$ | 每个视觉周期对应的力/力矩高频采样数 |
| $T_q=T_vR_q$ | 整个观测窗口内的关节高频采样总数 |
| $T_f=T_vR_f$ | 整个观测窗口内的力觉高频采样总数 |
| $C_I$ | RGB-D 图像通道数 |
| $H_I,W_I$ | 输入图像高度与宽度 |
| $D_s$ | 单臂关节与夹爪状态维度 |
| $D_w$ | 单臂力/力矩向量维度 |
| $D_a$ | 单臂动作维度 |
| $K$ | 输出动作块长度 |
| $D$ | 所有 Transformer token 的统一特征维度，即 $d_{\mathrm{model}}$ |
| $D_{\mathrm{ff}}$ | Transformer 前馈网络隐藏维度 |
| $N_h$ | 多头注意力的注意力头数 |
| $D_h=D/N_h$ | 每个注意力头的特征维度 |

## 2.3 视觉与摘要 token 数量

| 符号 | 含义 |
|---|---|
| $C_f$ | ResNet 最后一层二维特征图的通道数 |
| $H_f,W_f$ | 视觉特征图目标高度与宽度 |
| $N_v=H_fW_f$ | 每帧图像产生的视觉空间 token 数 |
| $N_q$ | 每个视觉时间槽保留的关节摘要 token 数 |
| $N_f$ | 每个视觉时间槽保留的力觉摘要 token 数 |
| $N_a=N_v+N_q+N_f$ | 单臂每个视觉时间槽的融合 token 总数 |
| $N_s$ | 从单臂时序状态提取的单臂摘要 token 数 |
| $N_g$ | 每个机械臂从全局视觉提取的条件查询 token 数 |
| $N_c$ | 双臂关系查询 token 数 |
| $N_{\mathrm{coord}}=2N_s+2N_g+N_c$ | 紧凑双臂协调序列长度 |

## 2.4 网络深度

| 符号 | 含义 |
|---|---|
| $L_q$ | 关节状态时序编码器层数 |
| $L_f$ | 力觉时序编码器层数 |
| $L_m$ | 单时刻多模态融合层数 |
| $L_t$ | 单臂跨视觉帧时序融合层数 |
| $L_g$ | 全局视觉跨帧时序融合层数 |
| $L_c$ | 双臂协调 Transformer 层数 |
| $L_r$ | 协调信息回注入层数 |
| $L_a$ | 双流同步动作解码器层数 |

## 2.5 主要张量

| 符号 | 含义 |
|---|---|
| $\mathbf X_k^c$ | 相机 $c$ 在视觉时间槽 $k$ 的 RGB-D 图像 |
| $\mathbf S_{k,r}^a$ | 机械臂 $a$ 在槽 $k$ 内第 $r$ 个关节/夹爪状态 |
| $\mathbf W_{k,r}^a$ | 机械臂 $a$ 在槽 $k$ 内第 $r$ 个力/力矩状态 |
| $\mathbf V_k^c$ | 相机 $c$ 在槽 $k$ 的视觉 token |
| $\mathbf Q_k^a$ | 单臂关节状态 token |
| $\mathbf F_k^a$ | 单臂力觉 token |
| $\mathbf H_k^a$ | 单臂在视觉时间槽 $k$ 内完成多模态融合后的表示 |
| $\mathbf H^a$ | 单臂完成跨帧时序融合后的状态 |
| $\mathbf G$ | 全局相机完成时序融合后的视觉表示 |
| $\mathbf C$ | 双臂协调 Transformer 的紧凑协调表示 |
| $\mathbf H^{\prime a}$ | 注入全局与双臂协调信息后的单臂状态 |
| $\mathbf Z_j^a$ | 动作解码器中的第 $j$ 个动作查询 token |
| $\widehat{\mathbf A}^a$ | 单臂连续动作块预测 |

# 3. 模型总体结构

BiMFT-Policy 由以下模块组成：

$$
\boxed{
\begin{aligned}
&\text{RGB-D 视觉编码器}\\
&\quad\downarrow\\
&\text{高频关节/力觉 token 编码器}\\
&\quad\downarrow\\
&\text{单时刻单臂多模态融合}\\
&\quad\downarrow\\
&\text{单臂跨帧时序融合}\\
&\quad\downarrow\\
&\text{全局视觉条件提取与双臂协调}\\
&\quad\downarrow\\
&\text{双流同步动作块解码器}\\
&\quad\downarrow\\
&\text{连续动作 MLP}
\end{aligned}}
$$

# 4. 输入数据组织

## 4.1 三路 RGB-D 图像序列

对任意相机 $c\in\{L,R,G\}$：

$$
\mathbf X^c
=
\left[
\mathbf X_1^c,\ldots,\mathbf X_{T_v}^c
\right]
\in
\mathbb R^{B\times T_v\times C_I\times H_I\times W_I}.
$$

单帧输入：

$$
\mathbf X_k^c
\in
\mathbb R^{B\times C_I\times H_I\times W_I}.
$$

其中 $C_I$ 包括 RGB 通道与深度通道。

## 4.2 高频关节与夹爪状态

对任意机械臂 $a\in\{L,R\}$：

$$
\mathbf S^a
=
\left[
\mathbf S_{k,r}^a
\right]_{k=1,r=1}^{T_v,R_q}
\in
\mathbb R^{B\times T_v\times R_q\times D_s}.
$$

单个高频状态：

$$
\mathbf S_{k,r}^a
\in
\mathbb R^{B\times D_s}.
$$

## 4.3 高频力/力矩状态

$$
\mathbf W^a
=
\left[
\mathbf W_{k,r}^a
\right]_{k=1,r=1}^{T_v,R_f}
\in
\mathbb R^{B\times T_v\times R_f\times D_w}.
$$

单个力觉状态：

$$
\mathbf W_{k,r}^a
\in
\mathbb R^{B\times D_w}.
$$

## 4.4 时间偏移

视觉时间偏移：

$$
\boldsymbol{\Delta}^{v}
\in
\mathbb R^{B\times T_v}.
$$

高频时间偏移：

$$
\boldsymbol{\Delta}^{h,q}
\in
\mathbb R^{B\times T_v\times R_q},\qquad
\boldsymbol{\Delta}^{h,f}
\in
\mathbb R^{B\times T_v\times R_f}.
$$

时间偏移相对于当前策略决策时刻定义，因此最新时刻的偏移为零或接近零。

# 5. 通用注意力算子

## 5.1 多头注意力

设 Query、Key、Value 分别为：

$$
\mathbf Q\in\mathbb R^{B\times N_q^{\ast}\times D},
\quad
\mathbf K\in\mathbb R^{B\times N_k^{\ast}\times D},
\quad
\mathbf V\in\mathbb R^{B\times N_k^{\ast}\times D}.
$$

其中 $N_q^{\ast}$ 是 Query token 数，$N_k^{\ast}$ 是 Key/Value token 数。

第 $m$ 个注意力头为：

$$
\operatorname{head}_m
=
\operatorname{softmax}
\left(
\frac{
(\mathbf Q\mathbf W_m^Q)
(\mathbf K\mathbf W_m^K)^\top
}{
\sqrt{D_h}
}
\right)
(\mathbf V\mathbf W_m^V).
$$

维度为：

$$
\operatorname{head}_m
\in
\mathbb R^{B\times N_q^{\ast}\times D_h}.
$$

多头注意力输出：

$$
\operatorname{MHA}(\mathbf Q,\mathbf K,\mathbf V)
=
\operatorname{Concat}
\left(
\operatorname{head}_1,\ldots,\operatorname{head}_{N_h}
\right)
\mathbf W^O,
$$

输出维度：

$$
\operatorname{MHA}(\mathbf Q,\mathbf K,\mathbf V)
\in
\mathbb R^{B\times N_q^{\ast}\times D}.
$$

## 5.2 前馈网络

$$
\operatorname{FFN}(\mathbf Y)
=
\sigma(\mathbf Y\mathbf W_1+\mathbf b_1)\mathbf W_2+\mathbf b_2,
$$

其中：

$$
\mathbf W_1\in\mathbb R^{D\times D_{\mathrm{ff}}},
\qquad
\mathbf W_2\in\mathbb R^{D_{\mathrm{ff}}\times D}.
$$

输入输出维度均为：

$$
\mathbf Y,\operatorname{FFN}(\mathbf Y)
\in
\mathbb R^{B\times N\times D}.
$$

## 5.3 Pre-Norm Cross-Attention Block

给定 Query 序列 $\mathbf Y$ 和 Memory $\mathbf M$：

$$
\begin{aligned}
\widetilde{\mathbf Y}
&=
\mathbf Y+
\operatorname{MHA}
\left(
\operatorname{LN}(\mathbf Y),
\operatorname{LN}(\mathbf M),
\operatorname{LN}(\mathbf M)
\right),\\
\mathbf Y^{\prime}
&=
\widetilde{\mathbf Y}
+
\operatorname{FFN}
\left(
\operatorname{LN}(\widetilde{\mathbf Y})
\right).
\end{aligned}
$$

若：

$$
\mathbf Y\in\mathbb R^{B\times N_Y\times D},
\qquad
\mathbf M\in\mathbb R^{B\times N_M\times D},
$$

则：

$$
\mathbf Y^{\prime}
\in
\mathbb R^{B\times N_Y\times D}.
$$

# 6. RGB-D 视觉编码

## 6.1 四通道 ResNet 特征提取

定义共享腕部视觉编码器：

$$
\mathcal E_{\mathrm{wrist}}:
\mathbb R^{C_I\times H_I\times W_I}
\rightarrow
\mathbb R^{C_f\times H_f\times W_f}.
$$

左右腕部相机共享 $\mathcal E_{\mathrm{wrist}}$。全局相机使用：

$$
\mathcal E_{\mathrm{global}}:
\mathbb R^{C_I\times H_I\times W_I}
\rightarrow
\mathbb R^{C_f\times H_f\times W_f}.
$$

对相机 $c$ 的第 $k$ 帧：

$$
\mathbf U_k^c
=
\mathcal E_c(\mathbf X_k^c)
\in
\mathbb R^{B\times C_f\times H_f\times W_f}.
$$

其中：

$$
\mathcal E_c=
\begin{cases}
\mathcal E_{\mathrm{wrist}}, & c\in\{L,R\},\\
\mathcal E_{\mathrm{global}}, & c=G.
\end{cases}
$$

## 6.2 通道投影与空间展平

先将特征通道投影到统一 token 维度 $D$：

$$
\overline{\mathbf U}_k^c
=
\mathcal P_v(\mathbf U_k^c)
\in
\mathbb R^{B\times D\times H_f\times W_f}.
$$

再展平空间维度：

$$
\mathbf V_k^c
=
\operatorname{Flatten}_{HW}
(\overline{\mathbf U}_k^c)
\in
\mathbb R^{B\times N_v\times D},
$$

其中：

$$
N_v=H_fW_f.
$$

## 6.3 视觉 embedding

为每个视觉 token 加入：

- 二维空间位置编码 $\mathbf E_p$；
- 相机类型编码 $\mathbf E_c$；
- 机械臂身份编码 $\mathbf E_a$，仅手眼相机使用；
- 模态编码 $\mathbf E_{\mathrm{vis}}$；
- 连续时间编码 $\boldsymbol{\Phi}(\Delta_k^v)$。

对手眼相机 $a\in\{L,R\}$：

$$
\widehat{\mathbf V}_k^a
=
\mathbf V_k^a
+
\mathbf E_p
+
\mathbf E_a
+
\mathbf E_a^{\mathrm{cam}}
+
\mathbf E_{\mathrm{vis}}
+
\boldsymbol{\Phi}(\Delta_k^v).
$$

维度：

$$
\widehat{\mathbf V}_k^a
\in
\mathbb R^{B\times N_v\times D}.
$$

对全局相机：

$$
\widehat{\mathbf V}_k^G
=
\mathbf V_k^G
+
\mathbf E_p
+
\mathbf E_G^{\mathrm{cam}}
+
\mathbf E_{\mathrm{vis}}
+
\boldsymbol{\Phi}(\Delta_k^v),
$$

维度：

$$
\widehat{\mathbf V}_k^G
\in
\mathbb R^{B\times N_v\times D}.
$$

# 7. 连续时间编码

给定相对时间偏移 $\Delta$，先构造 Fourier 特征：

$$
\boldsymbol{\psi}(\Delta)
=
\left[
\sin(\omega_1\Delta),
\cos(\omega_1\Delta),
\ldots,
\sin(\omega_M\Delta),
\cos(\omega_M\Delta)
\right].
$$

其中：

- $M$ 是 Fourier 频率数量；
- $\omega_m$ 是第 $m$ 个固定频率。

再经过时间 MLP：

$$
\boldsymbol{\Phi}(\Delta)
=
\operatorname{MLP}_t
\left(
\boldsymbol{\psi}(\Delta)
\right)
\in
\mathbb R^D.
$$

视觉时间编码整体维度：

$$
\boldsymbol{\Phi}(\boldsymbol{\Delta}^v)
\in
\mathbb R^{B\times T_v\times D}.
$$

高频时间编码（关节和力觉可独立计算）：

$$
\boldsymbol{\Phi}(\boldsymbol{\Delta}^{h,q})
\in
\mathbb R^{B\times T_v\times R_q\times D},\qquad
\boldsymbol{\Phi}(\boldsymbol{\Delta}^{h,f})
\in
\mathbb R^{B\times T_v\times R_f\times D}.
$$

---

# 8. 高频关节与力觉编码

## 8.1 关节与夹爪状态投影

对机械臂 $a$ 的第 $k$ 个视觉周期内第 $r$ 个状态：

$$
\mathbf q_{k,r}^a
=
\mathcal P_q(\mathbf S_{k,r}^a)
\in
\mathbb R^{B\times D},
$$

其中：

$$
\mathcal P_q:
\mathbb R^{D_s}\rightarrow\mathbb R^D.
$$

加上机械臂、模态和时间编码：

$$
\widehat{\mathbf q}_{k,r}^a
=
\mathbf q_{k,r}^a
+
\mathbf E_a
+
\mathbf E_{\mathrm{joint}}
+
\boldsymbol{\Phi}(\Delta_{k,r}^{h,q}).
$$

将一个视觉周期内的 $R_q$ 个 token 堆叠：

$$
\widehat{\mathbf Q}_k^a
=
\left[
\widehat{\mathbf q}_{k,1}^a,\ldots,
\widehat{\mathbf q}_{k,R_q}^a
\right]
\in
\mathbb R^{B\times R_q\times D}.
$$

## 8.2 力/力矩状态投影

$$
\mathbf f_{k,r}^a
=
\mathcal P_f(\mathbf W_{k,r}^a)
\in
\mathbb R^{B\times D},
$$

其中：

$$
\mathcal P_f:
\mathbb R^{D_w}\rightarrow\mathbb R^D.
$$

加入编码：

$$
\widehat{\mathbf f}_{k,r}^a
=
\mathbf f_{k,r}^a
+
\mathbf E_a
+
\mathbf E_{\mathrm{force}}
+
\boldsymbol{\Phi}(\Delta_{k,r}^{h,f}).
$$

堆叠后：

$$
\widehat{\mathbf F}_k^a
\in
\mathbb R^{B\times R_f\times D}.
$$

## 8.3 高频短序列 Transformer

关节编码器（$R_q$ 个 token 的短序列）：

$$
\mathbf Q_k^a
=
\operatorname{Enc}_q^{(L_q)}
\left(
\widehat{\mathbf Q}_k^a
\right)
\in
\mathbb R^{B\times R_q\times D}.
$$

力觉编码器（$R_f$ 个 token 的短序列）：

$$
\mathbf F_k^a
=
\operatorname{Enc}_f^{(L_f)}
\left(
\widehat{\mathbf F}_k^a
\right)
\in
\mathbb R^{B\times R_f\times D}.
$$

其中：

- $\operatorname{Enc}_q^{(L_q)}$ 表示包含 $L_q$ 层的关节时序 Transformer；
- $\operatorname{Enc}_f^{(L_f)}$ 表示包含 $L_f$ 层的力觉时序 Transformer。

# 9. 单时刻单臂多模态融合

对任意机械臂 $a$ 和视觉时间槽 $k$，输入为：

$$
\widehat{\mathbf V}_k^a
\in
\mathbb R^{B\times N_v\times D},
$$

$$
\mathbf Q_k^a
\in
\mathbb R^{B\times R_q\times D},
$$

$$
\mathbf F_k^a
\in
\mathbb R^{B\times R_f\times D}.
$$

## 9.1 关节摘要

使用 $N_q$ 个可学习摘要查询：

$$
\mathbf R_q
\in
\mathbb R^{1\times N_q\times D}.
$$

扩展到 batch：

$$
\mathbf R_q^{(B)}
\in
\mathbb R^{B\times N_q\times D}.
$$

关节摘要为：

$$
\overline{\mathbf Q}_k^a
=
\operatorname{MHA}
\left(
\mathbf R_q^{(B)},
\mathbf Q_k^a,
\mathbf Q_k^a
\right)
\in
\mathbb R^{B\times N_q\times D}.
$$

## 9.2 状态条件门控

将关节摘要池化为单个条件向量：

$$
\mathbf u_k^a
=
\operatorname{Pool}
\left(
\overline{\mathbf Q}_k^a
\right)
\in
\mathbb R^{B\times 1\times D}.
$$

门控网络输出：

$$
\alpha_{v,k}^a,
\alpha_{f,k}^a
=
\sigma
\left(
\operatorname{MLP}_{\mathrm{gate}}
(\mathbf u_k^a)
\right).
$$

若采用标量门控：

$$
\alpha_{v,k}^a,\alpha_{f,k}^a
\in
\mathbb R^{B\times 1\times 1}.
$$

## 9.3 视觉读取状态与力觉

状态 memory 为：

$$
\mathbf M_{s,k}^a
=
\left[
\mathbf Q_k^a;
\mathbf F_k^a
\right]
\in
\mathbb R^{B\times (R_q+R_f)\times D}.
$$

视觉更新：

$$
\widetilde{\mathbf V}_k^a
=
\widehat{\mathbf V}_k^a
+
\alpha_{v,k}^a
\operatorname{MHA}
\left(
\operatorname{LN}(\widehat{\mathbf V}_k^a),
\operatorname{LN}(\mathbf M_{s,k}^a),
\operatorname{LN}(\mathbf M_{s,k}^a)
\right).
$$

输出维度：

$$
\widetilde{\mathbf V}_k^a
\in
\mathbb R^{B\times N_v\times D}.
$$

经过 FFN：

$$
\mathbf V_k^{a,\prime}
=
\widetilde{\mathbf V}_k^a
+
\operatorname{FFN}
\left(
\operatorname{LN}(\widetilde{\mathbf V}_k^a)
\right),
$$

输出维度不变：

$$
\mathbf V_k^{a,\prime}
\in
\mathbb R^{B\times N_v\times D}.
$$

## 9.4 力觉反向读取视觉

力觉更新：

$$
\widetilde{\mathbf F}_k^a
=
\mathbf F_k^a
+
\alpha_{f,k}^a
\operatorname{MHA}
\left(
\operatorname{LN}(\mathbf F_k^a),
\operatorname{LN}(\widehat{\mathbf V}_k^a),
\operatorname{LN}(\widehat{\mathbf V}_k^a)
\right).
$$

输出维度：

$$
\widetilde{\mathbf F}_k^a
\in
\mathbb R^{B\times R_f\times D}.
$$

经 FFN 得到：

$$
\mathbf F_k^{a,\prime}
\in
\mathbb R^{B\times R_f\times D}.
$$

上述视觉读取力觉与力觉读取视觉的过程重复 $L_m$ 层。

## 9.5 力觉摘要

定义 $N_f$ 个力觉摘要查询：

$$
\mathbf R_f
\in
\mathbb R^{1\times N_f\times D}.
$$

得到：

$$
\overline{\mathbf F}_k^a
=
\operatorname{MHA}
\left(

# 22. 模型核心特征总结

BiMFT-Policy 的核心设计可以概括为：

1. **完整空间视觉表示**：每帧保留 $N_v=H_fW_f$ 个 RGB-D 空间 token。
2. **多频率输入**：每个视觉时间槽绑定 $R_q$ 个高频关节 token 和 $R_f$ 个力觉 token。
3. **单臂局部融合**：每只机械臂先独立融合手眼视觉、关节和力觉。
4. **当前帧锚定时序建模**：历史多模态信息通过 Cross-Attention 写入当前状态。
5. **臂条件全局视觉提取**：左右臂依据各自状态从全局图像中提取不同信息。
6. **紧凑双臂协调**：跨臂通信使用摘要和关系 token，而非直接混合全部局部 token。
7. **协调回注入**：共享协调信息再写回左右完整局部状态。
8. **双流同步动作解码**：左右动作分别输出，但动作生成的每一层继续交换未来动作特征。
9. **连续动作块回归**：最终使用两个独立 MLP 输出左右连续动作块。
